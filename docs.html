Technical Explanation

The Codebase

TaskFlow runs entirely in your browser using the trifecta of web development:

  • HTML: Provides the semantic structure and defines the application's elements (`todo-form`, `todo-list`).
  • CSS (style.css): Defines visual aesthetics utilizing custom CSS variables for easy theming (`--primary`, `--background-light`).
  • JavaScript (app.js): Controls all logic. Modifies the Document Object Model (DOM) and utilizes memory storage (`localStorage`).

Key Functions

  • renderTasks(): Wipes the DOM array, and iterates through the `tasks` state building the string-interpolated HTML blocks.
  • saveTasks(): Serializes array object as a JSON string and updates Local Storage.
  • addTask(): Reads user string input, applies a unique timestamp as an ID, and sets default boolean state.
  • deleteTask(id): Utilizes JS Array Iteration `filter` to strip out the object matching the provided ID.
  • toggleComplete(id): Loops through task objects using `map` arrays and inverses the specific boolean payload.
